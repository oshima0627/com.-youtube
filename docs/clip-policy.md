# 切り抜きの型

最終更新: 2026-09-10。根拠は [`docs/analytics-2026-09-02.md`](analytics-2026-09-02.md) 3-4節と
[`docs/analytics-2026-09-10.md`](analytics-2026-09-10.md)。

**これは方針であって、機械の検査ではない。** ここに書いたから守られる、とは考えないこと。
機械が見ているのはタイトルの型（`clipper/metadata.py`）と権利のゲート（`clipper/gate.py`）だけ。

## 何を切るか

競合ショートの再生上位15本を数えたら、3類型しかなかった。

| 類型 | 本数 | こちらで作れるか |
|---|---:|---|
| ミニぎし（やまとの姪）関連 | 5 | **作れない**（第三者・未成年） |
| コラボ相手が主役 | 4 | **作れない**（許諾は BRDOCK だけで第三者は射程外） |
| **特定メンバー1人の一言・一挙動** | 6 | **作れる。ここに絞る** |

**いま切っているのは「本編企画の中の盛り上がり区間」で、3類型のどれでもない。**
企画の説明が要る区間は、フィードで初見の人には届かない。

### 具体的な条件

- **主役は1人**。誰の何が面白いのかが、1本につき1つだけ言えること
- **前提の説明が要らない**。企画名・ルール・経緯を知らなくても成立すること
- **冒頭2秒で本題**。企画説明パートから始めない
- タイトルは本文でその1人を名指しし、`#shorts` とメンバータグを付ける
  （`clipper/metadata.py` の `short_title()` が組み立てる。名簿外の名前は弾かれる）

## 尺

**「短くすれば伸びる」根拠は無い。** 競合ショート72本で尺と再生数は無相関（r=0.050）。
市場の中央値が31秒でこちらが49〜68秒に固まっている、というのは「作り手の慣習が違う」
までしか言っていない。

**それでも短尺を試す理由は完走率のほう。** スワイプ離脱が37%あり、完走率だけは
尺と機械的に結びつく。`config/settings.yaml` の `formats.short_experiment.max_seconds: 35`
はそのための枠で、**まだ一度も使っていない。**

在庫18本は全部55〜68秒なので、**在庫では実験できない**（切り直す＝再アップロードで
1,600ユニット／本）。**まだ上げていない `M7ZxIL_b39E` を短尺で書き出すときが最初の機会。**

## 何を測るか

**中身の良し悪しは、露出が出るまで測れない。** 公開16本・合計64再生では
1回の差が乱数と区別できない（内部スコアと再生数の相関は r=0.175）。

順番は決まっている。

1. 在庫18本を9日で出し切る（2026-09-11〜09-19、予約済み）
2. `python scripts/distribution_check.py` で判定する（判定日 2026-09-29）
3. **`pass` なら**、そこで初めて「どの切り抜きが良いか」を比べられる母数になる
4. **`fail` なら**、投稿頻度が原因という仮説は否定される。作り方を変えても動かない

## 時間を使わないもの（理由つき）

| やらない | 理由 |
|---|---|
| 登録者を目標にする | 露出が無いので動かない。16本・64再生で登録者0は当然の値 |
| サムネイルの改善 | ショートの主戦場はフィードで、そもそもカスタムサムネイルが使えない（電話番号確認ができない） |
| 在庫を増やす | 既に9日分ある。詰まっているのは制作ではなく配信 |
| 内部スコアの改善 | 再生数を説明していない（r=0.175）。説明できる母数が無い |
| 合格線を下げる | `distribution_target` は結果を見る前に決めてある。下げれば必ず「達成」できてしまう |
