## ショートのタイトルの型

伸びている上位は例外なくこの形だった。

```
赤組のマシュマロキャッチがダサくて最高すぎるwwwwww #コムドット #赤組 #マシュマロ
減量終わりにマックを食べるひゅうがが飯テロすぎた #コムドット #コムドット切り抜き
本名が特徴的すぎて『笑っていいとも！』に出演したキラキラネーム📛✨ #コムドット
```

| 要素 | 内容 |
| --- | --- |
| ハッシュタグ | **本文に入れる。** 概要欄ではなくタイトルに |
| メンバー名 | 誰の場面かを入れる。ただし映像で確認できたときだけ |
| 語尾 | 「〜すぎる」「〜が最高」と断定して終わる。要約で止めない |
| 【】 | **使わない。** 長尺の作法で、ショートでは見当たらない |

`metadata.short_title()` がこの型を組み立てる。既存5本は
`upload.retitle()` で反映済み。**映像を作り直す必要が無いときは上げ直さない。**
`videos.update` は50ユニットで、`videos.insert` の1,600に対して桁が違い、
動画IDも再生数も維持される。

## 長尺で伸びているもの

上位は「個人にフォーカスした面白シーン集」だった。

```
366,000  554s  【妖精】コムドットに来た妖精（編集済み）
113,000  424s  ゆうたが絶好調で面白すぎる
 71,000  180s  【神童】ゆうたの可愛いシーン集
 38,000  263s  【革命児】やまとの面白シーン集
 30,000  509s  【最高】脳内一致ゲーム面白シーンを集めたら最高すぎた part1
```

**複数の場面をつないだ「集」が主流。** こちらは「1本の連続区間だけを切り出す」
方針を取っている。これは令和の虎のガイドラインから借りた自主規制で、コムドットには
該当する成文ルールが無い。**市場で勝っている形とは逆を向いている。**

BRDOCK への依頼文では編集方法について聞いていない。回答が来たら、
複数場面の再構成が可能かを追加で確認する価値がある。それが通れば、
長尺の作り方を「1企画まるごと」から「個人フォーカスの場面集」へ変えられる。
