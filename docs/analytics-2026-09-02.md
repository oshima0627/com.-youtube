## 3. 測って分かった具体的な差

### 3-1. 投稿頻度

コムの巣窟の直近8本の公開日: 09-02×2 / 09-01×2 / 08-31×2 / 08-30×2。
**毎日2本、今日も出している。**

こちらは 08-18〜08-22 に14本を出したあと、**11日間ゼロ**。

### 3-2. 尺（ただし尺は再生数を説明しない）

競合ショート **72本**の尺と再生数を個別に取得した。

- 尺 **中央値 31秒** / 最小 14秒 / 最大 133秒
- **30秒以下が 33/72本、45秒以下が 47/72本**
- 49秒以上は 22/72本

こちらは13本すべて 49〜68秒、うち9本が 66〜68秒に固まっている。
**市場の典型（31秒）から2倍ずれており、しかも分散がほぼ無い。**

`config/settings.yaml` の `max_seconds: 68` の根拠は
「伸びている競合ショートは67〜73秒」という **tora-kirinuki（令和の虎）側の実測**で、
**コムドット市場で測り直したものではなかった。**

**ただし「短くすれば伸びる」という結論は出ていない。** 同じ72本で尺と再生数の
相関は **r = 0.050**（ほぼ無相関）。尺の帯ごとに見ても単調ではない。

| 尺 | 本数 | 再生中央値 |
|---|---:|---:|
| 0-25秒 | 22 | 33,662 |
| 26-35秒 | 19 | 36,502 |
| 36-50秒 | 9 | 65,339 |
| 51-70秒 | 14 | 31,296 |
| 71秒以上 | 8 | 90,587 |

**最も伸びている帯は71秒以上。** 短さが理由で伸びているのではない。
言えるのは「市場の作り手は31秒前後で作っている」までで、
**尺を変えれば数字が動くという根拠はこの標本には無い。**

### 3-3. タイトルの作り

日本語タイトルの競合ショート27本と、自分の13本を機械的に数えた。

| | 競合 | 自分 |
|---|---:|---:|
| ハッシュタグ数（中央値） | **6** | 2 |
| メンバー名を含む | **22/27** | **2/13** |
| `#shorts` を含む | 46/120 | **0/13** |
| タイトル長（中央値） | 68字 | 43字 |

`docs/market-scan.md` には「メンバー名を入れる」と書いてあり、
`clipper/metadata.py` の `short_title()` にも `extra_tags` 引数がある。
**書いてあるのに、実際の13本では使われていない。**
原因は単純で、**`short_title()` はどこからも呼ばれていなかった。**
タイトルは `python -m clipper upload --title` で素通しされていた。

### 対応（2026-09-02 実施）

型を docs から機械の検査へ移した。

- `SHORT_TAGS` に **`#shorts` を追加**（`#コムドット #コムドット切り抜き #shorts`）
- `short_title(body, members)` が **`#やまと` などのメンバータグを組み立てる。**
  名簿 `metadata.MEMBERS` に無い名前は `InvalidTitle` で弾く
- 100文字を超えるときは**末尾のタグを丸ごと落とす**（途中で切らない）
- `validate_title(title, is_short=True)` が **`#shorts` とメンバー名を必須にする。**
  本文で名指ししていればタグは無くてもよい
- CLI に `--members` と、**`retitle` サブコマンドを追加**（以前は
  `upload.retitle()` があるのに呼び出す口が無かった）

`pytest` 140件 通過。

### メンバー名は字幕からは取れない（実測）

公開済みショート19本について、区間内の自動字幕にメンバー名が出るかを数えた。

```
16/19 が「(なし)」
名前が出たのは3本のみ（すべて『やまと』。1〜3回）
```

**つまり誰が映っているかは字幕から決められない。** `--members` に渡す名前は
**映像を見て確かめる**しかない（`docs/third-party-audit-2026-08-17.md` と同じ手順）。
`metadata.MEMBERS` の名簿検査は、推測した名前が紛れ込むのを防ぐための最後の砦。

### 3-4. 伸びている題材

競合ショート再生上位15本の内訳（タイトルから判定）:

- **ミニぎし（やまとの姪）関連が5本**（792,000 / 398,000 / 342,000 / 311,000 / 451,000）
- **コラボ相手が主役のものが4本**（くれいじーまぐねっと / むくえな / エスポ / ヒカル）
- 残りは**特定メンバー1人の一言・一挙動**（ひゅうがの心拍、ひゅうがの逃げ足など）

こちらが切ってきたのは**本編企画の中の盛り上がり区間**で、この3類型のどれでもない。
なお**コラボ回とファン参加回は第三者の肖像の問題で使えない**（`docs/third-party-audit-2026-08-17.md`）。
上位15本のうち少なくとも4本は、こちらでは最初から作れない題材にあたる。
