## ルール
1. 実験期間中は**長尺を作らない・予約しない**（既に予約済みのものは残す）。
2. ショートを **1日2本**。素材の別々の区間から（互いにも、過去の公開動画とも映像が重ならない）。枠は 19:00 と 20:00 JST（埋まっていれば 21:00）。
   - **A（試験）**: 結論先出し、25〜35秒。最初の1〜3秒に一番面白い台詞・瞬間。
   - **B（対照）**: 従来型、45〜65秒。前振り→オチ。
   - 19:00 枠の A/B は日ごとに入れ替える（初日 19:00=A）。各5本以上・14日以上。
3. タイトルは メンバー名「引用」…型。語尾を毎回変える（〜すぎる で揃えない）。期間中に素材を2本以上使う。
4. 最後の1〜2秒に、クリップに結びついた具体的な二択の問い。概要欄1行目も具体的な問い。押し付けない。
5. 毎本、文脈テロップ（上部の前振り・下部の状況説明）で独自の価値を足す。権利者の条件・再利用ポリシーに反するものは作らない。permission.yaml を確認し続ける。
6. この台帳に毎日、各ショートの variant / 素材 / 区間 / タイトル / 尺 / 予約時刻を記録する。
7. 判定日: 各ショートの views / likes / comments（Data API）で A と B を比較（n・中央値・最大）。インプレッション・CTR・維持率は取れない。因果は主張しない。長尺の再開は運営者に確認する。
