# 切り抜き許諾の問い合わせ

## 送信先

株式会社BRDOCK 公式サイトの問い合わせフォーム
https://brdc.co.jp/ （ページ下部「お問合せ / CONTACT」）

※ 2026-08-14 時点でフォームの存在と項目を実見して確認済み。回答目安は1〜2日。

## 各項目の入力値

| 項目 | 入力値 |
|---|---|
| 企業名 | 個人（法人化している場合は法人名） |
| お名前 | 本名を記載する |
| Email | 連絡が取れるアドレス |
| お問合せ内容 | **その他の問い合せ** |
| 詳細 | 下記の本文 |

## 詳細欄の本文

```
コムドット様の切り抜き動画に関する許諾のご相談です。

■ 企画の概要
・チャンネル名：コムドット名場面ch【切り抜き】
・ハンドル：@com.-meibamen
・内容：コムドット様の公式チャンネルで公開されている動画から場面を抜き出し、
　字幕や構成を加えた切り抜き動画として投稿するもの
・運営：個人
・現在は未公開の状態です。ご許諾をいただけた場合にのみ公開いたします。

■ ご相談の背景
2022年5月17日公開の動画内で、切り抜きに関してやまと様よりご言及があったと
承知しておりますが、公式に文書化されたガイドラインを確認できなかったため、
条件をご確認のうえで開始したく、ご連絡を差し上げました。

■ ご教示いただきたい点
1. 貴社の動画を素材とした切り抜き動画の投稿は可能でしょうか。

2. 可能な場合、YouTubeパートナープログラムによる収益化は可能でしょうか。
   収益の取り扱いについて条件がございましたらご教示ください。

3. 出典やクレジットの表記について、ご指定の形式はございますか。
   （概要欄への公式チャンネルURLの記載などを想定しております）

4. チャンネルアイコンやサムネイルへの、メンバーの皆様のお写真・
   イラスト等の使用は可能でしょうか。

5. 対象から外すべき動画はございますか。
   （企業様との案件回、他クリエイター様とのコラボ回、テレビ・
   　イベント関連の回などを想定しております）

■ お約束
ご回答の内容には従います。ご許諾いただけない場合は開設を見合わせます。
また公開開始後であっても、削除・修正等のご要望には速やかに対応いたします。

お忙しいところ恐れ入りますが、ご確認のほどよろしくお願いいたします。
```

## 送信前に決めておくこと

- **「現在は未公開」と書くかどうか。** 回答を待ってから公開する前提の文面にしてある。
  先に公開して走らせる方針なら、この行と「開設を見合わせます」の一文は書き換える。
  ただし後から方針を変えるより、最初に約束した内容を守るほうが交渉上は強い。
- **チャンネル名とハンドルを確定させてから送る。** 文面に固有名を書いているため、
  送信後に変えると齟齬が出る。

## 回答が来たら

- 回答メールは削除せずに保管する。これが唯一の許諾の証拠になる。
- 回答内容をこのファイルに追記し、[memory](../../.claude) 側の
  「書面許諾なし」という前提も更新すること。
- 回答が来ない場合、それは許諾ではない。無回答を承諾とみなさない。
