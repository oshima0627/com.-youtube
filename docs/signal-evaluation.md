# 信号の実測評価（2026-08-14）

tora-kirinuki から移植した4信号合成が、コムドットで実際に効くかを測った記録。
再現するには `python scripts/evaluate_signals.py <video_id> ...`。

## 方法

ヒートマップ（most replayed）を正解とする。ヒートマップが存在する4本を対象に、
**ヒートマップを候補算出から外して**候補を出し、その区間の実ヒート値で採点した。

- 「上位3平均/基準線」= 候補上位3本の実ヒート平均 ÷ 動画全体の平均ヒート値。
  1.00倍なら適当に選んだのと同じ。
- 「正解を当てた本数」= ヒート最大の区間を1位候補に含められた動画の数。

対象: `RGm5F2m12as` `fDiW0YbLd-Q` `zvM7bkbavDQ` `wKuTNfA6Xhg`（いずれも公開24日以上）。

## 結果（移植したままの重み）

| 信号 | 上位3平均/基準線 | 正解を当てた本数 |
| --- | ---: | ---: |
| コメントのみ | **1.97倍** | **2/4** |
| 語彙＋コメント | 1.95倍 | 1/4 |
| 移植元の配分（全信号） | 1.76倍 | 0/4 |
| 語彙のみ | 1.17倍 | 0/4 |
| 音量のみ | 0.70倍 | 0/4 |

**移植した合成方式は、コメント単独に負けた。**

### 音量が効かない理由

令和の虎は虎が怒鳴るので音量が盛り上がりに直結する。コムドットは5人が常時
にぎやかに喋っていて音量の分散が小さく、スパイクが場面の質を示さない。
実際、コメントに音量を足すと3本中2本で明確に悪化した。

なお `fDiW0YbLd-Q` は音声取得が403で落ちたため音量が空。「音量のみ 0.70倍」は
この欠損で下振れしている。欠損を除いた3本でも0.94倍で、基準線を超えない。

### 語彙が弱い理由

「やばい」「すご」「怖」は日常語として頻出しすぎる。`[笑い]` も58分で96回、
35秒に1回の頻度で出るため、単独では場面を特定できない。

## 反映した重み

| 定数 | 変更 | 根拠 |
| --- | --- | --- |
| `W_LOUD` | 0.35 → **0.0** | 単独で基準線以下。足すと悪化 |
| `COMBO_BONUS` | 0.35 → **0.0** | `W_LOUD` を 0 にしても、この加点が語彙の重み（最大0.10）を上回り裏口から音量が効いていた |
| `W_LEX` | 歓声0.30/驚き0.18/笑い0.12/いじり0.10 → **0.10/0.05/0.04/0.03** | 単独では基準線をわずかに超える程度。同点を崩す用途に留める |
| `W_COMMENT` | 0.30（据え置き） | 唯一まともに効く信号 |

再計測後、全信号の成績は 1.76倍 0/4 → **1.99倍 1/4**。コメント単独（1.97倍 2/4）と
実質同等になった。n=4 なので 1/4 と 2/4 の差は誤差の範囲とみなしている。

## コメントは新着でも使えるか

ヒートマップは公開24日未満で存在しないため使えない。コメントに同じ問題がないかを確認した。

| 経過日数 | コメント取得 | 時刻言及の箇所 |
| ---: | ---: | ---: |
| 4日 | 400件 | 42 |
| 9日 | 400件 | 51 |
| 19日 | 400件 | 86 |
| 20日 | 400件 | 164 |
| 53日 | 400件 | 85 |

**公開4日でも42箇所ある。** 新着で機能するので主軸に置ける。

## この評価の限界

- **n=4。** しかも全て公開24日以上（ヒートマップが必要なため）。新着で同じ精度が
  出るかは、この方法では原理的に測れない
- 正解に使っているヒートマップ自体が「視聴者が繰り返し見た区間」であり、
  「切り抜きとして伸びる区間」とは別物。最終的な答え合わせは投稿後の再生数でしかできない
- 重みは4本に合わせて決めたので、過剰適合の可能性がある。本数が増えたら測り直すこと
